# 🎵 NOIR — Music Player

A modern, responsive music player built with **HTML, Vanilla JavaScript, and Tailwind CSS v4**.


NOIR is designed with a dark, minimal, and immersive interface inspired by modern music streaming platforms. The goal was to create a smooth and simple music experience while keeping the interface clean and visually focused.

## ✨ Features

* 🎧 Play and pause songs
* ⏭️ Next / Previous track controls
* 🔊 Volume control
* 🔁 Repeat mode
* ❤️ Add and remove songs from Favorites
* 🔎 Search songs by title or artist
* 🎵 Multiple music categories
* 👨‍🎤 Artist section and artist pages
* 📱 Fully responsive design
* 💾 Favorites saved with `localStorage`
* 🎨 Modern dark UI with neon orange accents
* ⚡ Smooth interactions and animations
* 🎶 Dynamic playlist rendering

## 🎼 Categories

NOIR includes different music categories to make discovering songs easier:

* Popular
* Pop Classic
* Nostalgic
* Sonati
